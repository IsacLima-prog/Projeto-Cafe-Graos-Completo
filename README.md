# Projeto-Cafe-Graos-Completo
Café &amp; Grãos: site responsivo de cafeteria desenvolvido com HTML, CSS e JavaScript. Possui catálogo com 12 cafés, carrosséis de produtos e métodos de preparo, galerias de imagens, descrições expansíveis, visualização em lista, tema claro e escuro e ajuste de fonte. Projeto educacional focado em desenvolvimento front-end e acessibilidade.
